## Build & Development Commands

- **Dev server**: `pnpm dev` (Vite with HMR)
- **Build**: `pnpm build` (runs `tsc -b && vite build`, output in `dist/`)
- **Lint**: `pnpm lint` (ESLint)
- **Format check**: `pnpm format:check` (Prettier)
- **Format write**: `pnpm format:write` (Prettier)
- **Lint + format check**: `pnpm lint:all`
- **Preview production build**: `pnpm preview`
- **Regenerate API client**: `pnpm api:generate` (from OpenAPI spec)

No test framework is currently configured.

## Architecture

React 19 + TypeScript 5.9 single-page application built with Vite 7.

**Entry flow**: `index.html` → `src/main.tsx` (MSW bootstrap in dev → React root + router) → `src/routes/__root.tsx` (Chakra Provider + QueryClientProvider) → route tree

**Key libraries**:

- **UI**: Chakra UI v3 — pre-built snippet components live in `src/components/ui/` (generated, do not edit manually)
- **Routing**: TanStack Router with file-based routing — routes live in `src/routes/`, route tree is auto-generated at `src/routeTree.gen.ts`
- **Auth**: Context in `src/context/auth-context.tsx` (calls real SDK `authenticate()`), injected into router context for `beforeLoad` guards. JWT stored in `src/auth-token.ts` module-level store.
- **API Client**: Generated by `@hey-api/openapi-ts` from `.docs/openapi-bundle.yaml` into `src/api/`. Uses Axios + TanStack React Query. Run `pnpm api:generate` to regenerate.
- **Forms**: RJSF (react-jsonschema-form) with `@rjsf/chakra-ui` theme. Reusable `SchemaForm` wrapper in `src/components/schema-form.tsx`. Forms are driven by JSON schemas from `src/api/schemas.gen.ts` with `uiSchema` for customization.
- **Mocking**: MSW (browser service worker) intercepts API calls in dev. Mock data in `src/mocks/db.ts` using `@msw/data` with Zod schemas. Handlers in `src/mocks/handlers/`.

**Routing layout**:

- `__root.tsx` — Chakra Provider + QueryClientProvider wrapper
- `_authenticated.tsx` — pathless layout route acting as auth guard
- `_authenticated/workspace.tsx` — workspace shell (toolbar + sidebar + outlet)

**API layer**:

- `src/api/` — **fully generated**, wiped on `pnpm api:generate`. Never place manual files here.
- `src/api-config.ts` — manual file outside the generated directory. Exports `API_BASE_URL`, `createClientConfig`, and `setupAuthInterceptor()`.
- `src/auth-token.ts` — module-level JWT token store shared between React auth context and Axios interceptor.
- `src/mocks/handlers/` — MSW request handlers, one file per API domain.
- `src/mocks/fixtures/` — Static typed response data (used by handlers and tests). Every fixture must be explicitly typed with generated types from `@/api/types.gen`.
- `src/mocks/db.ts` — `@msw/data` Zod-based collections for dynamic mock state.
- See [.tasks/CONVENTIONS.md](.tasks/CONVENTIONS.md) for API layer rules (auth pattern, mock handler conventions, adding new endpoints).

**Tooling**:

- Package manager: pnpm
- ESLint flat config with typescript-eslint, react-hooks, react-refresh, and eslint-config-prettier
- Prettier for formatting
- Separate tsconfig files: `tsconfig.app.json` (app code, ES2022) and `tsconfig.node.json` (build tooling, ES2023)
- Path alias: `@/*` maps to `./src/*`

**TypeScript constraints** (`erasableSyntaxOnly` enabled):

- No enums, no constructor parameter properties, no namespaces
- Use `import type` for type-only imports (`verbatimModuleSyntax`)
