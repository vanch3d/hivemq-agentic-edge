# Task Brief: Internationalization (react-i18next)

## Requirements

1. Add `react-i18next` and `i18next` to the project.
2. Set up a basic configuration with `en-US` as the default (and only) locale.
3. **Every user-facing string** must be defined in i18n from the beginning — no hardcoded strings in components.
4. Plan a good key structure for the translation file, especially for RJSF-based forms.
5. Provide an **automatic process** that maps i18n keys to JSON Schema and uiSchema properties (`title`, `description`, `placeholder`) so form field labels are translated by convention.
