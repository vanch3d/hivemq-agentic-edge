# Task 00001: Plan & Progress

## Architecture Decisions

- **Router context pattern**: Auth state is injected into TanStack Router's context object (not accessed via React hooks in `beforeLoad`), because `beforeLoad` runs outside the React render tree.
- **Provider placement**: `AuthProvider` wraps `RouterProvider` in `main.tsx`. Chakra's `Provider` wraps the rendered UI tree inside `__root.tsx`.
- **Pathless layout route**: `_authenticated.tsx` uses TanStack Router's `_` prefix convention — no URL segment, acts purely as an auth guard layout.
- **No enums**: `erasableSyntaxOnly` is enabled in tsconfig, so union types and `as const` objects are used instead.
- **`verbatimModuleSyntax`**: All type-only imports use `import type`.

## File Structure

```
src/
  components/
    ui/               # Chakra UI v3 generated snippets
    workspace/
      toolbar.tsx     # Top toolbar with color mode + user menu
      sidebar.tsx     # Side navigation + logout
  context/
    auth-context.tsx  # Mock auth context + provider + useAuth hook
  routes/
    __root.tsx        # Root layout (Chakra Provider + Outlet)
    index.tsx         # "/" redirect based on auth state
    login.tsx         # Login page
    _authenticated.tsx            # Auth guard layout
    _authenticated/
      workspace.tsx               # Workspace shell layout
      workspace/
        index.tsx                 # Default workspace content
  routeTree.gen.ts   # Auto-generated by TanStack Router plugin
  main.tsx           # Entry point
```
